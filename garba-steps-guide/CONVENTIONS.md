# Repository Naming Conventions

Use these conventions for all files and changes in this guide.

## Names

- Repository / project directory: `garba-steps-guide`
- Documentation directory: `docs/`
- Main reference: `docs/garba-steps-108.md`
- Markdown files: lowercase kebab-case, such as `content-review-notes.md`
- Branches: lowercase kebab-case, optionally prefixed by purpose, such as `docs/step-name-review` or `fix/gujarati-table-formatting`
- Commit messages: short imperative or conventional-commit format, e.g. `docs: clarify step labels`

## Content conventions

- Keep UTF-8 encoding for Gujarati script.
- Preserve the source's serial numbering unless changes are intentional and described.
- Preserve the supplied labels: `[T]`, `[D]`, and `[M]`.
- Use headings and Markdown tables consistently.
- Do not imply descriptive/informal labels are universally standardized.
