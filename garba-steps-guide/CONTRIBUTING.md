# Contributing to garba-steps-guide

**Collab. What's Costing You Time.**

Thanks for helping improve this Garba, Dandiya and Raas reference.

## Naming conventions

- Keep repository, directory and file names in lowercase kebab-case.
- Store reference documentation in `docs/`.
- Use descriptive filenames, such as `garba-steps-108.md`.
- Keep serial numbers stable unless a deliberate correction is documented.
- Use UTF-8 encoding to preserve Gujarati script.
- Keep headings consistent and Markdown tables readable.

## Content quality

- Preserve source terminology and distinguish traditional names from descriptive labels.
- If a name varies by region or teacher, note the variation rather than claiming universal usage.
- For corrections, include a reliable reference or clear regional context where possible.
- Do not silently remove or renumber entries.

## Suggested workflow

1. Create a focused branch using lowercase kebab-case, for example `docs/correct-step-transliteration`.
2. Make one logical change per pull request.
3. Explain the change and any sources in the pull request description.
4. Review Gujarati rendering and table alignment before submitting.
