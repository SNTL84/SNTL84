# garba-steps-guide

**Collab. What's Costing You Time.**

A structured reference of 108 Garba, Dandiya and Raas steps, movements, formations, rhythms and styles, with Gujarati names, English meanings and serial numbers.

Names and footwork vary by region and teacher. Items tagged `[D]` are descriptive working labels, not fixed terms.

## Tags

- `[T]` traditional or widely used name
- `[D]` descriptive or informal label
- `[M]` modern or fusion style

## Naming convention

- Repository: lowercase kebab-case (`garba-steps-guide`)
- Files and folders: lowercase kebab-case
- Documentation files live in `docs/`
- Use descriptive Markdown filenames and keep existing serial numbering intact.
